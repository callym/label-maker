# label-maker

A simple web interface for connecting a Brother P-touch label maker.

I've been running it on a Raspberry Pi with a PT-P600 and it works fine.

## Features

- Upload images, adjust B&W threshold and invert the colours if needed.
- Add text which is rendered with an included pixel font.
- View a preview of what the label will look like.
- Add multiple images/text and print them as one label with cut marks, to stop waste.
